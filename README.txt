# Tu Punto de Venta — Portafolio

## Cómo usarlo
1. Descomprime la carpeta.
2. Abre `script.js` y reemplaza `https://TU-ENLACE-DEL-POS.vercel.app` por la URL real de tu sistema.
3. Copia tu APK Release a `descargas/android/` y conserva el nombre `app-release.apk`.
4. Coloca los PDF en `descargas/manuales/` con estos nombres:
   - `manual-android.pdf`
   - `manual-ios.pdf`
   - `manual-usuario.pdf`
5. Abre `index.html` en el navegador para revisar la página.
6. Cuando esté lista, publica la carpeta en Vercel.

## Seguridad
No subas el archivo `.jks`, contraseñas, claves privadas, archivos `.p12` ni credenciales de Firebase.
La página es pública: cualquier archivo incluido en ella podrá ser descargado por quien tenga el enlace.
